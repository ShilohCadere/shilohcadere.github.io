# Shiloh Cadere — Professional Portfolio

Static HTML, CSS, and JavaScript website.

Published address: https://shilohcadere.github.io/

## Edit

Edit `index.html`, page directories, and files under `assets/`. Preview with a local static server. Keep the directory structure intact.

## Publish

GitHub repository Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Commits to `main` are published by GitHub Pages. `.nojekyll` keeps these static files from being processed as a Jekyll site.

The professional portfolio is a GitHub user site at the domain root. Cadere Productions is a project site beneath `/cadere-productions/`; its internal paths include that prefix.

## Content

Project descriptions and screenshots reflect the development snapshots described on the site. Furlong screenshots use seeded example data, not a live user account. No application databases, secrets, or runtime session files are included.
