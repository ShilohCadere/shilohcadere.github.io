Barcode Crossover Analysis

A reproducible workflow for estimating barcode crossover from expected and unexpected reference alignments, with a comparison before and after a protocol modification.

View repository ↗
Implementation

Nextflow · Python · samtools · minimap2 · matplotlib

Project stage

Portfolio analysis workflow

Data context

Repository demonstration results

Turn alignments into an interpretable comparison.

The analytical question is whether unexpected reference alignments change between two runs. The workflow separates read preparation, alignment, quantification, and summary so the conclusion can be traced back to the counts.

What I built

  • Convert unaligned BAM files to FASTQ with samtools.
  • Align reads to a combined reference using minimap2.
  • Quantify primary alignments and summarize target and non-target reference counts.
  • Compare estimated crossover in summary tables and a separate plotting script.
Evidence in the repository

What can be inspected.

The committed crossover summary reports 82 non-target primary alignments out of 93,416 before, and 14 out of 99,644 after. The reported percentages are 0.0878% and 0.0141%: approximately a 6.2-fold difference in the repository example.

Implementation choices.

A combined reference

Target and unexpected reference alignments are quantified within the same alignment approach.

Keep stages separate

Nextflow handles execution; Python handles analytical summaries and visualization.

Preserve the underlying counts

The summary table includes mapped-read totals and non-target counts alongside the reported percentages.

Scope & limitations

Where the evidence stops.

These are repository demonstration results, not evidence of a clinical validation or a production laboratory improvement. Containerization and direct workflow integration of plotting remain listed as future work.
